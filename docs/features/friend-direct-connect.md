# 好友直连

入口：资源管理 → 服务器 → 好友直连。

房主先用所选实例进入世界，选择“对局域网开放”，刷新检测端口（也可手动填入游戏显示的端口），再开启房间。复制邀请信息，通过自己的聊天工具发给好友。好友粘贴后检测地址，选择匹配的 Minecraft / Loader 实例并启动。MOD 列表需要双方自行确认一致。1.20 及支持 Quick Play 的版本自动连接；更旧版本启动后在多人游戏中粘贴页面提供的地址。

## 网络行为

- 只使用两位玩家本机和本地路由器。没有中央房间目录、账号匹配服务、STUN、TURN、外部 IP 查询或第三方流量中继。
- 房主有一个本机双栈 TCP 端口适配器，将 IPv6/IPv4 入站数据原样转发到本机 Minecraft 局域网端口，以支持仅绑定 IPv4 的 Java。游戏协议、认证与加密数据不被改写。启动器不生成离线认证绕过参数。
- IPv6 优先，IPv4 次之，最后尝试局域网地址。邀请仅接受字面量 IP，不通过 DNS 或第三方服务解析。客户端检测证明 TCP 可达，不等于游戏认证、MOD 兼容性或公网稳定性已经通过。
- UPnP 用 SSDP 在本地 IPv4 接口发现 InternetGatewayDevice，读取 WANIPConnection/WANPPPConnection。HTTP 控制地址必须属于同一个私网 IP；不接受跨主机控制地址、重定向、外部 XML 实体或超大响应。
- 使用随机开放端口、TCP 映射、300 秒租期、120 秒续租。建立前检查同端口已有规则；删除和续租前核对内部地址、端口及唯一说明，避免动到其他程序的映射。不自动创建永久规则。只支持永久租约的旧路由器会报告失败，可手动映射。
- 最多 32 个并发连接，流量使用背压。关闭房间销毁连接与监听器并请求删除自身映射；进程异常退出时路由器短租约自然过期。不得关闭或绕过系统防火墙。

## 限制

本机有公网 IPv6 地址不代表入站防火墙和运营商一定放行。网关 WAN 地址为 100.64.0.0/10 时明确报告 CGNAT；WAN 为 RFC1918 私网时报告上级 NAT。未发现网关时无法仅凭本地数据断言 CGNAT。手机热点、校园网也可能限制入站。上述环境仍可加入其他可达房主。

没有公网路径时可在同一局域网使用，页面不会声称已经实现公网穿透。需要完整内网穿透能力时应使用专门工具。房主必须保持游戏和 FAIONYX 运行；不要启用启动后自动退出。此功能不改变此前待确认的启动器退出/游戏进程生命周期逻辑。

邀请不是密码，只包含候选地址、端口、实例信息与有效期（24 小时）。只向可信好友分享，避免公开传播自己的 IP 地址。关闭房间即关闭本机入口；下一次开启会分配新端口。公网地址变更后重新开启并复制邀请。

## 邀请格式 v1

前缀 `FAIONYX-DIRECT-1:` 后是以下 JSON 的 UTF-8 Base64URL；也接受原始 JSON。最多 16 KiB、12 个地址。

```json
{
  "format": "FAIONYX-DIRECT",
  "version": 1,
  "name": "实例名称",
  "minecraftVersion": "1.21.1",
  "loader": "fabric",
  "loaderVersion": "加载器版本",
  "endpoints": [{ "host": "192.168.1.20", "port": 35000, "kind": "lan" }],
  "expiresAt": "ISO 8601 UTC 有效期"
}
```

拒绝回环、链路本地、组播、保留地址、CGNAT、非 IP 主机和非法端口。`kind` 根据地址重新计算，不信任邀请自报的公网类型。

实现依据：[UPnP WANIPConnection 1.01](https://upnp.org/specs/gw/UPnP-gw-WANIPConnection-v1-Service.pdf)、[RFC6598 共享地址](https://www.rfc-editor.org/rfc/rfc6598.html)。
