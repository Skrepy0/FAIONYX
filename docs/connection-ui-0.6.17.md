# 联机页面重设计 · 0.6.17

## 页面结构

| 页面     | 顶部                                                   | 主体                                             | 辅助与反馈                                                           |
| -------- | ------------------------------------------------------ | ------------------------------------------------ | -------------------------------------------------------------------- |
| 好友直连 | 标题、房间状态；网络概览（公网候选、世界端口、连接数） | 网络限制提示；创建房间、加入好友两张独立流程卡片 | 折叠诊断、手动 IPv4 映射、邀请检测结果、不可达地址、旧版手动连接地址 |
| 服务器   | 标题、添加按钮；搜索、刷新、同步工具区                 | 左侧可搜索列表，右侧选中详情；窄屏改为上下排列   | 加载、空收藏、无搜索结果、未连通、实例缺失、编辑与删除确认           |

### 视觉规则

- 主操作：创建房间、检测邀请、启动并连接；使用主题强调色。
- 次操作：刷新、同步、复制、编辑；使用中性描边按钮。删除只在详情或批量操作区出现，并二次确认。
- 状态不能仅靠颜色表达：标签同时显示“检测中 / 在线 / 未连通”等文字。
- 公网地址明确标为“候选”，不把发现本地网卡地址等同于可做公网房主。
- 所有新颜色来自 `--card`、`--bg`、`--accent`、`--accent-soft`、`--text`、`--text-dim`、`--border`、`--ok`、`--danger` 等主题变量。
- 表单高度 44px、主要按钮至少 40px；键盘焦点可见，支持减少动态效果偏好。
- 窄屏保留完整功能，通过纵向滚动访问，不挤压输入框。

## 组件划分

`src/renderer/src/components/connection/`

- `ConnectionPanel.vue`：统一分区容器、标题、说明、步骤标记和头部操作插槽。
- `ConnectionStatus.vue`：带文字的中性、成功、失败、处理中状态。
- `NetworkOverview.vue`：只读网络概览和诊断折叠区；刷新事件交给父级处理。
- `ServerListItem.vue`：服务器摘要、选中态、多选复选框、双击连接事件。
- `ServerDetails.vue`：状态、介绍、玩家与延迟、实例绑定、连接与管理操作。
- `connection.css`：两页共享的主题表单、卡片、提示、响应式和无障碍样式。

编排层：`FriendConnect.vue` 保留直连状态、轮询和原 API 调用；`ServersView.vue` 保留同步、绑定、启动、多选删除，管理搜索和选中服务器。

## 功能与数据边界

- 直连的 UPnP、手动映射、邀请生成/检测、兼容实例筛选和实际启动流程保留。
- 必要提示包括 CGNAT、手机热点、校园网、可能无法做房主但仍可能加入、专业内网穿透建议、分享邀请风险、模组一致性和正常游戏认证。
- 新增编辑真实链路：`editServer()` → `IPC.serversEdit` → 主进程校验 → `servers.json` 持久化。
- 编辑保留服务器 ID、实例与文件夹关联、Loader 元数据和历史；校验空名称、无效地址以及同一实例的重复地址。
- 编辑后的名称由启动器管理，后续同步不覆盖手工命名。
- 不写入 Minecraft 的 `servers.dat`。因此修改地址或删除启动器记录后，游戏原列表里的旧地址仍可能在下次同步时重新导入。
- 刷新请求带序号，编辑地址后旧请求不会覆盖新地址的状态；启动、绑定期间有禁用反馈。
